# Exercise 07: Scenario 01 — Introduction to Windows Disk Management

**Author:** kuronoi  
**Project:** Windows System Administration Lab

## 1. Introduction
This exercise introduces Windows Disk Management and its role in managing computer storage devices, partitions and volumes.

**Note:** This was a simulated training exercise. No actual disk partitions or volumes were modified.

## 2. Objectives
- Understand the purpose of Windows Disk Management.
- Identify disk partitions and volumes.
- Understand the purpose of formatting.
- Recognise the importance of protecting data during disk operations.

## 3. Tools and Concepts Covered

| Tool / Concept | Purpose |
|---|---|
| Disk Management | Manages disks, partitions and volumes. |
| Windows + R | Opens the Run dialog. |
| `diskmgmt.msc` | Opens Disk Management. |
| Disk Partition | A section of a physical storage disk. |
| Formatting | Prepares a volume with a file system. |

## 4. Key Lessons
- Disk Management helps administrators organise storage devices.
- Partitions divide physical disks into separate storage sections.
- Volumes provide storage areas that Windows can use.
- Formatting prepares a volume for file storage.
- Incorrect disk operations can result in data loss.
- Important data should be backed up before making disk changes.

The exercise improved my understanding of Windows Disk Management, storage organisation and basic disk administration.
