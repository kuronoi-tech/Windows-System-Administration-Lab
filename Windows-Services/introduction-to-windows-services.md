# Exercise 01: Introduction to Windows Services Management

**Project:** Windows System Administration Lab  
**Author:** kuronoi  
**Status:** Completed (Simulated Practical Exercise)

## 1. Objective
To understand Windows services, their functions and how administrators manage them using Services Manager.

## 2. Scenario Description
An employee reported that their computer could not print documents. Investigation revealed that the Print Spooler service was stopped.

The IT administrator needed to identify the service, understand its status and determine the appropriate troubleshooting action.

## 3. Tools Used
- Windows 11
- Services Manager (`services.msc`)
- Windows Run Command
- Print Spooler Service

## 4. Procedure
1. Identified Windows services as background programs responsible for specific system tasks.
2. Opened Services Manager using `services.msc`.
3. Reviewed the available service statuses.
4. Identified the meaning of Running, Stopped and Paused.
5. Examined Automatic, Automatic (Delayed Start), Manual and Disabled startup types.
6. Identified starting the required Print Spooler service as the initial troubleshooting action.
7. Confirmed the importance of testing the affected function after troubleshooting.

## 5. Results
The simulated exercise demonstrated how Windows services operate and how administrators can inspect and manage them.

It also established that a stopped service may prevent certain system functions from working correctly.

## 6. Lessons Learned
- Meaning and purpose of Windows services.
- How to open Services Manager.
- How to interpret service statuses.
- Different Windows service startup types.
- Importance of testing services after troubleshooting.
- Importance of documenting maintenance activities.

## 7. Conclusion
This simulated exercise improved my understanding of Windows Services Management and its importance in maintaining computer functionality.

**Note:** This was a simulated training exercise. No actual Windows services were changed.
