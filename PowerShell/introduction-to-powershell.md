# Exercise 06: Scenario 01 — Introduction to PowerShell

**Author:** kuronoi  
**Project:** Windows System Administration Lab

## 1. Introduction
This exercise introduces Windows PowerShell and its role in system administration and task automation.

**Note:** This was a simulated training exercise. No actual system administration changes were performed.

## 2. Objectives
- Understand the purpose of PowerShell.
- Identify common PowerShell cmdlets.
- Understand the Verb-Noun naming convention.
- Recognise commands used to inspect Windows processes, services and directories.

## 3. Commands Covered

| Command | Purpose |
|---|---|
| `Get-Date` | Displays current date and time. |
| `Get-Process` | Lists running processes. |
| `Get-Service` | Displays Windows services. |
| `Get-ChildItem` | Lists files and folders. |
| `Get-Location` | Displays the current directory. |

## 4. Key Lessons
- PowerShell is a command-line shell and scripting language.
- Cmdlets commonly follow the Verb-Noun naming convention.
- PowerShell helps IT technicians automate and manage Windows systems.
- Understanding basic cmdlets is important for system administration.
