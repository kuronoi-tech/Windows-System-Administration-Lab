# Exercise 02: Windows Password Recovery and Account Management

**Project:** Windows System Administration Lab  
**Author:** kuronoi  
**Status:** Completed (Simulated Practical Exercise)

## 1. Objective
To understand Windows password recovery procedures and learn how to assist users who cannot access their accounts.

## 2. Scenario Description
An employee reported being unable to sign in to their Windows 11 computer after forgetting their password.

The simulated investigation focused on identifying the account type and selecting an appropriate authorised recovery method.

## 3. Tools and Resources
- Windows 11 Settings
- Microsoft Account Recovery
- Windows User Account Management
- IT Support Documentation

## 4. Investigation and Recovery Procedure
1. Verified the employee's identity and authorisation.
2. Determined whether the employee used a Microsoft account or local Windows account.
3. Selected the appropriate authorised password recovery method.
4. Considered potential effects on encrypted files and saved credentials.
5. Assisted with the password recovery process.
6. Asked the employee to sign in using the recovered account credentials.
7. Verified access to authorised applications and files.

## 5. Results
The simulated recovery process successfully restored the employee's ability to access their Windows account.

The proposed verification confirmed that the employee could sign in and access authorised resources.

## 6. Security Considerations
- Verify user identity before making account changes.
- Use official and authorised password recovery procedures.
- Never share passwords with unauthorised individuals.
- Protect account credentials and confidential information.
- Consider the impact of password resets on encrypted files and stored credentials.

## 7. Lessons Learned
- Difference between Microsoft and local Windows accounts.
- Basic Windows password recovery procedures.
- Importance of identity verification.
- Importance of testing account access after recovery.
- Proper documentation of IT support incidents.

## 8. Conclusion
This simulated exercise improved my understanding of Windows password recovery, account security and basic IT support procedures.

**Note:** This was a simulated training exercise. No actual employee account or password was changed.
