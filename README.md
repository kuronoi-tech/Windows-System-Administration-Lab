## 1. About This Project

The Windows System Administration Lab is a practical learning project focused on developing and demonstrating Windows administration skills.

It documents practical exercises involving system information, user account management, file management, Windows services, command-line tools, PowerShell and system monitoring.

## 2. Project Objectives

- Understand Windows operating system administration.
- Identify computer hardware and system specifications.
- Manage Windows user accounts and permissions.
- Understand file and folder management.
- Work with Windows administrative tools.
- Develop command-line and PowerShell skills.
- Document technical procedures and findings.

## 3. Tools and Technologies

- Windows 11 Pro Education
- Windows Settings
- Command Prompt
- Windows PowerShell
- Task Manager
- Computer Management
- Windows Services

## 6. Learning Approach

Each exercise follows a practical learning approach:

1. Define the objective.
2. Identify the tools required.
3. Perform the practical exercise.
4. Record observations and findings.
5. Document the results.
6. Review lessons learned.
