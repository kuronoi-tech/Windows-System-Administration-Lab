# Exercise 01: Basic Command Prompt Navigation

**Author:** kuronoi  
**Project:** Windows System Administration Lab

## 1. Objective
To understand basic Command Prompt commands used to navigate directories, view files and create folders.

## 2. Scenario
An IT support technician needs to use Command Prompt to navigate folders, inspect directory contents and organise files.

This was a simulated training exercise.

## 3. Commands Learned

| Command | Function |
|---|---|
| `cd` | Displays or changes the current directory |
| `cd ..` | Moves to the parent directory |
| `dir` | Lists files and folders |
| `mkdir` | Creates a new directory |
| `cls` | Clears the Command Prompt screen |
| `hostname` | Displays the computer name |

## 4. Practical Procedure
1. Open Command Prompt.
2. Use `cd` to view or change the current directory.
3. Use `dir` to display files and folders.
4. Use `mkdir Reports` to create a folder.
5. Use `cd ..` to return to the parent directory.
6. Use `cls` to clear the screen.

## 5. Results
The exercise demonstrated the purpose and correct use of basic Command Prompt navigation commands.

The commands were studied through simulated scenarios. No practical execution results are claimed.

## 6. Lessons Learned
- Command Prompt supports directory navigation and file organisation.
- `dir` displays directory contents.
- `mkdir` creates directories.
- `cd ..` moves to the parent directory.
- `cls` clears the screen.

## 7. Conclusion
This exercise introduced basic Command Prompt navigation and provided foundational knowledge for Windows command-line administration.
