# Exercise 03: Creating and Organising Windows Files and Folders

**Project:** Windows System Administration Lab  
**Author:** kuronoi  
**Status:** Completed (Simulated Practical Exercise)

## 1. Objective
To learn how to create, organise and manage files and folders using Windows File Explorer.

## 2. Scenario Description
A company required an organised folder structure for storing employee documents.

The required structure included Administration, Finance, Human Resources and Reports folders.

## 3. Tools Used
- Windows 11 File Explorer
- Keyboard Shortcuts
- Folder Management

## 4. Procedure
1. Opened Windows File Explorer.
2. Created the main Company Documents folder.
3. Created four subfolders:
   - Administration
   - Finance
   - Human Resources
   - Reports
4. Identified a Finance document stored in the wrong location.
5. Used Cut and Paste to move the document into the Finance folder.
6. Checked the folder structure and verified the document location.

## 5. Results
The simulated exercise produced the following folder structure:

Company Documents/
- Administration/
- Finance/
- Human Resources/
- Reports/

The misplaced Finance document was moved into its appropriate folder.

## 6. Lessons Learned
- How to create folders and subfolders.
- How to organise company documents.
- Difference between copying and moving files.
- Useful Windows keyboard shortcuts.
- Importance of verifying file locations.

## 7. Conclusion
This simulated exercise improved my understanding of Windows file and folder management and the importance of organised document storage.

**Note:** This was a simulated training exercise. No actual company files or folders were modified.
